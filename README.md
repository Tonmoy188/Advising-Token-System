## Pre-Advising System (PAS)
The Pre-Advising System (PAS) is a conceptual frontend solution designed to streamline the university course registration and advising process. It addresses student bottlenecks such as prerequisite checks, timetable conflicts, and advising queues through a clean, modern, and accessible interface.

# Features
* Dashboard: Provides a summary of advising status, current token information, and system notifications.

* Prerequisite Check: Verifies course eligibility based on a student's completed academic history.

* Completed Courses: Displays academic history, grades, and credit-weighted GPA calculation notes.

* Course Registration: Allows students to select courses and view real-time section statuses.

* Section Selection: Enables detailed selection of faculties, rooms, and class timings.

* Routine Check: Visual schedule mapping to detect and prevent time clashes across the week.

* Token System: Digital queuing mechanism for advising time slots.

# Tech Stack
HTML5, CSS3 (Modular and modern responsive design)

# Key Modules & Implementation
* Layout Structure: Shared stylesheet ensuring a clean, modern, and cohesive layout across all functional pages.

* Dynamic Content Rendering: Clear, table-based layouts for prerequisite verification and academic history.

* Interactive States: Uses modern CSS components for warnings, clashing rules, and status pills.

## Usage
The repository is a static frontend concept. You can open the .html files in any modern web browser to navigate through the interface modules.
